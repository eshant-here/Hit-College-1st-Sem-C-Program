## 📖 About The Repository

Welcome to my **1st Semester C Programming** repository! 🚀  
This repository documents my programming journey and lab assignments as an engineering undergraduate at **HIT College**. It contains modular, well-commented, and tested C code ranging from foundational arithmetic problems to complex looping algorithms and logic builders.

### 🌟 Highlights
- **Beginner-Friendly:** Well-structured solutions with clear variable names and formatting.
- **Categorized Modules:** Organized cleanly by concepts (Loops, Switch-Case, Conditionals, Arithmetic).
- **Core Curriculum Aligned:** Covers standard First-Year Engineering computer science syllabus topics.
- **Ready to Compile:** Compatible with GCC, Clang, MinGW, Turbo C++, Dev-C++, and VS Code.

## 🛠️ How to Compile & Run

### 1. Prerequisites
Make sure you have a C compiler installed on your system:
- **Windows:** MinGW-w64, MSVC, or Dev-C++ / Code::Blocks
- **Linux:** `sudo apt install build-essential` (GCC)
- **macOS:** `xcode-select --install` (Clang)

Check your installation in terminal:
```bash
gcc --version
```

### 2. Clone the Repository
```bash
git clone https://github.com/eshant-here/Hit-College-1st-Sem-C-Program.git
cd Hit-College-1st-Sem-C-Program
```

### 3. Compile Any Program
To compile a file (example: `fibonaic_serise.c`):

```bash
# On Linux / macOS:
gcc Programming-Using-Loop/fibonaic_serise.c -o fibonacci

# On Windows (Command Prompt / PowerShell):
gcc Programming-Using-Loop\fibonaic_serise.c -o fibonacci.exe
```

> [!TIP]
> For mathematical programs utilizing `<math.h>` (e.g. `quadratic_equatation.c` or `areaoftraingle_3side.c`), link the math library with `-lm` on Linux/macOS:
> ```bash
> gcc conditional-statement/quadratic_equatation.c -o quadratic -lm
> ```

### 4. Run the Executable
```bash
# On Linux / macOS / Git Bash:
./fibonacci

# On Windows:
fibonacci.exe
```
